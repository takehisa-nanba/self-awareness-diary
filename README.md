# Self Awareness Diary (感情深掘り日記)

自分の感情を記録し、その背後にある欲求（マズローの欲求階層説など）を深掘りして可視化するアプリ。
「なぜ今、この気分なのか？」を客観視することで、自己理解を深めます。

## 📱 機能
- **感情入力:** 5段階の顔アイコンで今の気分を記録。
- **要因タグ:** 「なぜその気分なのか？」をタグで選択（仕事、人間関係、達成感、安らぎなど）。
- **データ保存:** 高速なNoSQLデータベース「Isar」を使用し、端末内にデータを安全に永続化。
- **AIによる感情分析:** Gemini APIを活用し、記録した日記の内容を分析して、客観的なフィードバックやインサイトを提供。
- **環境情報の自動記録:** 日記作成時の位置情報（地名）と天気を自動で取得し、記録データに付与。

## 🛠️ 技術スタック
- **Framework:** Flutter
- **Language:** Dart
- **Database:** Isar
- **State Management:** Provider
- **Key Libraries:**
  - `google_generative_ai` (Gemini API)
  - `geolocator`, `http` (外部サービス連携)
  - `table_calendar`, `fl_chart` (UI表現)
- **Environment:** Project IDX / VS Code
