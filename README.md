# 自己覚知日記 (Self-Awareness Diary)

これは、日々の出来事や感情を記録し、AIと共に自己理解を深めるための多機能な日記アプリケーションです。Flutterで構築されています。

## 💡 アプリケーションのコンセプト

日々の感情や出来事を記録することは、自己理解を深め、心の健康を保つ上で非常に重要です。「自己覚知日記」は、このプロセスをAIとテクノロジーの力でサポートします。単なる記録に留まらず、AIによる客観的な分析や内省を促す問いかけを通じて、ユーザーが自分自身をより深く見つめ直す機会を提供します。

## ✨ 実装済みの機能

### 1. 豊富な情報を持つ日記記録
- **気分の記録**: その日の気分を複数のタグと0-100のスコアで記録できます。
- **出来事の記述**: 何が起こったのかを自由に記述できます。
- **自己分析**: 出来事に対する自分自身の振り返りを記録する欄があります。

### 2. AIによる客観的な分析
- **感情安定度スコア**: GoogleのGemini AIがあなたの日記の内容を分析し、「感情の安定度」を0-100のスコアで客観的に評価します。
- **AIからのコメント**: なぜそのスコアになったのか、AIからの簡潔な理由も表示されます。
- **自己認識とのギャップ**: あなたが付けた気分スコアとAIの分析スコアに大きな差がある場合、それをハイライト表示し、自己認識と客観的評価の違いに気づくきっかけを提供します。
- **内省を促す質問**: 日記を書いている最中に、AIが内容に応じた質問を投げかけ、より深い自己分析をサポートします。

### 3. 環境情報の自動記録
- **位置情報**: 日記を作成した場所の緯度・経度を自動で記録します。
- **天気情報**: その時の天気を記録します。
- **カスタムロケーション**: 「自宅」「職場」など、特定の場所に名前を付けることができます。一度登録すれば、過去にそのGPS範囲内で書かれた日記にも自動で場所名が適用されます。

### 4. 多彩な振り返り機能
- **履歴 (カレンダービュー)**: カレンダー形式で過去の日記を簡単に探し、閲覧できます。内省が未記入の記録はハイライト表示されます。
- **分析 (グラフビュー)**: 
  - **ムード推移グラフ**: 選択した期間内のムードスコアの推移を折れ線グラフで視覚的に確認できます。期間が1日の場合は、時間帯別の推移グラフに自動で切り替わります。
  - **ムードタグ分布グラフ**: 期間内にどの感情タグが最も多く使われたかを棒グラフで確認し、感情の傾向を把握できます。
  - **高機能な期間選択**: カレンダー上で記録のある日を確認しながら、直感的に分析したい期間（複数日または単日）を選択できます。

### 5. 便利な補助機能
- **開発者向けオプション**: 設定画面から、動作確認のためのランダムなテストデータを大量に生成する機能があります。

### 6. UIの統一と編集フローの改善
- **統一されたUI**: 全ての画面で共通のヘッダー (`AppShell`) を使用し、一貫したUIとナビゲーション体験を提供します。
- **詳細画面からの直接編集**: 履歴の詳細画面から「この記録を研磨する」ボタンをタップすることで、直接その記録の自己分析（Step 3）を編集できるようになりました。これにより、過去の記録を見返しながら、よりスムーズに内省を深めることができます。

## 📅 今後の開発予定 (Planned Features)

現在計画中、または将来的に実装を検討している機能です。

- **クラウド同期とバックアップ**: ユーザー認証を導入し、日記データをクラウドに同期・バックアップすることで、データの安全性と複数デバイスからのアクセスを確保します。
- **リッチなメディアアタッチメント**: 日記に写真、動画、音声などのメディアファイルを添付できる機能を追加し、より豊かな記録を可能にします。
- **カスタマイズ可能なUI**: テーマ、フォント、表示形式など、ユーザーがアプリの見た目を自由にカスタマイズできるオプションを提供します。
- **高度なAIトレンド分析**: 期間ごとの感情の推移、特定の出来事と気分の関連性など、より深掘りしたAIによるトレンド分析機能を提供します。
- **通知とジャーナリングリマインダー**: 定期的な日記の記入を促す通知機能や、特定の出来事を振り返るリマインダーを設定できる機能を追加します。

## 🛠️ 使用技術

- **フレームワーク**: Flutter
- **データベース**: [Isar](https://isar.dev/) (高速なオンデバイスDB)
- **状態管理**: [Provider](https://pub.dev/packages/provider)
- **AI**: [Google Gemini API](https://ai.google.dev/) (`google_generative_ai`)
- **位置情報**: `geolocator`, `geocoding` (Google Maps API)
- **天気情報**: OpenWeather API
- **UIコンポーネント**:
  - `table_calendar`: カレンダー表示
  - `fl_chart`: グラフ描画
  - `flutter_speed_dial`: フローティングアクションボタン

## 🚀 セットアップ

1. **APIキーの準備**:
   以下のAPIキーを取得し、プロジェクトルートに `.env` ファイルを作成して記述します。
   ```
   GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
   GOOGLE_MAPS_API_KEY="YOUR_GOOGLE_MAPS_API_KEY"
   OPEN_WEATHER_API_KEY="YOUR_OPEN_WEATHER_API_KEY"
   ```

2. **依存関係のインストール**:
   ```bash
   flutter pub get
   ```

3. **コード生成の実行**:
   Isarのモデルファイルを変更した場合は、以下のコマンドを実行してください。
   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```

4. **アプリケーションの実行**:
   ```bash
   flutter run
   ```
